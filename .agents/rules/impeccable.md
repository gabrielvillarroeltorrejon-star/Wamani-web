# Impeccable Design Skill

Enforce strict structural and system design rules on all UI components to ensure visual harmony, accessibility, and a highly professional polish:

- **Typography Scale**: Use a consistent typography scale. Ensure a strong contrast between headings (which should have bold weight, tight letter-spacing/tracking, and shorter line-heights) and body text (which needs regular weights and readable line-heights around 1.5 - 1.6).
- **Visual Hierarchy**: The most important element on the screen should immediately draw the eye. Use weight, size, and color contrast to establish clear hierarchy. De-emphasize secondary text using lighter text colors (e.g., gray-500 or rgba(0,0,0,0.6)).
- **Spatial Balance & Grid System**: Use consistent, predictable spacing based on a 4pt or 8pt grid system. Margins, gaps, and paddings should follow increments like 4px, 8px, 12px, 16px, 24px, 32px, 48px, 64px, etc.
- **Absolute Alignment**: Ensure perfect alignment. Icons, text, and containers must be visually vertically and horizontally centered where expected. Use flexbox or CSS grid appropriately.
- **Color Contrast & Accessibility**: Ensure text has high readability and meets WCAG accessibility standards. Never place low-contrast gray text on a gray background. Ensure interactive elements are clearly distinguishable.
- **Consistency**: Keep UI patterns (e.g., button structures, input heights, padding styles) identical across all views.
